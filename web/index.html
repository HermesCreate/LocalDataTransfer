    FEATURES

    功能描述

    • ⇄
      双向传输

      本地 → 服务器上传，或服务器 → 本地下载。

    • ▦
      多服务器

      一次选择多台 SSH 别名，按顺序逐台传输，下载自动按别名分目录。

    • ◈
      适合大文件

      整文件传输、不压缩，适合视频与大型数据集。

    • ↻
      可续传

      使用 --partial 保留未完成文件，停止后再次开始即可继续。
